# 1401 中文汉化版 · 使用说明书

> 对应版本：官方 1401 v2.9 ｜ 适用：OpenCore 黑苹果，macOS 15.5 及以上（含 macOS 26 Tahoe）

## 一、这是什么

1401 是 NullMoth 官方提供的工具，用来在 OpenCore 黑苹果上安装、更新和移除 NVIDIA（NullMoth）驱动。本汉化版**只翻译界面文字**，功能逻辑、驱动文件、校验方式与官方完全一致。

- 汉化范围：主界面五个页面、驱动设置窗口（19 项设置）、EFI 检查规则（27 条）、窗口标题、全部按钮与提示
- 本包**不含驱动本体**：驱动由 app 运行时从官方源下载，并对照官方 SHA-256 校验
- 许可证：PolyForm Noncommercial 1.0.0，仅供非商业用途免费使用；与 NullMoth 官方无隶属关系
- Required Notice: Copyright NullMoth Systems

## 二、第一次打开

1. 解压 zip，把 `1401汉化.app` 拖进「应用程序」文件夹
2. 首次打开若提示「无法验证开发者」：右键点 app → **打开**；或到 系统设置 → 隐私与安全性 → 点「仍要打开」（app 为 adhoc 自签名，与官方分发方式相同）
3. **动手之前先备份 EFI**：到「工具 · 挂载 EFI」挂载引导分区，把整个 EFI 文件夹复制到 U 盘
4. 保持引导本机启动的 U 盘或硬盘（OpenCore 所在盘）始终插在电脑上，1401 要改的就是那上面的配置

## 三、主界面五个页面

| 页面 | 用途 |
|---|---|
| **本机** | 硬件检测表、驱动安装四步流程、更新检查、实验性功能开关 |
| **问题检查** | 按 27 条规则检查 EFI 与 config.plist，逐条给出说明和修复步骤 |
| **工具 · 挂载 EFI** | 挂载 EFI 分区、选择 config.plist、打开日志文件夹 |
| **USB 端口** | 查看并定制 USB 端口映射 |
| **发送报告** | 收集硬件/内核/崩溃日志并发送给官方（**自愿**，不点不发） |

**驱动安装四步**（在「本机」页）：

1. **获取驱动** —— 下载官方驱动包并校验哈希
2. **先看清楚再动手** —— 列出将要改动的每一处，此步不写入任何内容（macOS 会要求输入密码）
3. **安装** —— 自动备份 OpenCore 配置，只执行清单内的改动，并在启动菜单加入 `1401: Remove NVIDIA driver`
4. **重启** —— 若系统提示扩展被阻止，到 系统设置 → 隐私与安全性 点「允许」，再重启一次

## 四、驱动设置窗口

从主界面进入「驱动设置」，共 19 项，分「显示」「性能」两组：

- **显示**：HDR10、10 位色深、可变刷新率、输出色深 / 颜色格式 / 动态范围、数字振动、动态超级分辨率、HiDPI 模式、旋转缩放、环视多屏、笔记本面板亮度
- **性能**：帧率上限、低延迟模式、着色器缓存上限、多张 N 卡、为应用指定显卡、内置按应用配置、系统内存保留

使用要点：

- 每项改动都会**先展示将要写入的内容并请求确认**，确认后才写入
- 下拉选「默认」表示交给驱动自行决定；「开启 / 关闭」为显式设定
- **显示类设置属于引导参数，重启后生效**；改动前请确认自己能进系统
- 不确定某项作用时，把鼠标停在说明文字上读一遍，保持「默认」最安全

## 五、装好驱动后的常见情况

- **显卡名称或显存显示奇怪**：系统信息里的名称/显存由驱动注入，名称不标准不代表驱动没工作
- **Optimus 双显卡笔记本**：内屏通常由核显驱动，外接 USB-C / HDMI 才直连 N 卡，这是正常形态
- **保留 `-v` 详细启动模式**：方便看启动报错，不必去掉
- **Lilu / AMFIPass 相关报错**：先确认 kext 版本配套、SIP（`csr-active-config` 常为 `0x0FFF`）、SecureBootModel 等设置
- **不要随意屏蔽核显或其他显卡**，除非明确知道后果
- 驱动下载需要联网；网络不通时先检查系统代理设置

## 六、汉化版专属注意事项（重要）

- **不要在汉化版里点自动更新**：官方更新会覆盖整个 app，界面会变回英文（功能不受影响）。想升级请下载对应版本的汉化包
- 若按仓库 `zh-CN/mac-resources/` 自行替换资源文件来汉化，设置窗口**标题栏**仍是英文 `Driver settings`（标题写在可执行文件里），不影响使用
- 本汉化不触碰驱动、kext、EFI 内容，也不改任何校验逻辑

## 七、出问题怎么办

1. 先看「问题检查」页给出的规则说明和修复步骤
2. 重启时保留 `-v`，观察启动日志定位失败点
3. 用「工具 · 挂载 EFI」把之前备份的 EFI 还原回去
4. 启动菜单里的 `1401: Remove NVIDIA driver` 可一键移除驱动
5. 需要官方协助时用「发送报告」（自愿上传）
