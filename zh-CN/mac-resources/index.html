你的 Mac，一目了然

1401 为运行 macOS 15.5 或更高版本（含 macOS 26 Tahoe）的 OpenCore 黑苹果安装 NullMoth 驱动。请保持引导本机启动的 U 盘或硬盘（OpenCore 所在盘）始终插在电脑上：1401 要改的就是那上面的设置。

操作流程

  1. 获取驱动。
  2. 先看清楚再动手。 1401 会读取你的 OpenCore 配置，并列出它将做出的每一项更改——不做任何实际改动。（macOS 会要求输入密码。）
  3. 安装。 先备份你的 OpenCore 配置，然后精确执行上面列出的更改，安装驱动，并在启动菜单中添加 1401: Remove NVIDIA driver（卸载 NVIDIA 驱动）回退项。
  4. 重启。 如果 macOS 提示系统扩展被阻止，请打开 隐私与安全性，点击允许，然后再重启一次。

更新


1401 会检查最新的 NullMoth 驱动和最新的 1401 应用。应用会自我更新并重新打开；驱动会先下载，与官方公布的 SHA-256 校验后，按与上面相同的流程安装，安装前会先备份你的 OpenCore 配置。


   


抢先更新。 新驱动会先推送给打开此选项的用户，等他们的机器验证没有问题后再向所有人发布。打开它可提前一两天拿到新版本，并在出现问题时上报日志。


  



更新到 macOS 26 Tahoe


在 macOS 15 上，为本机准备 Tahoe 会安装或更新驱动并暂停其加载，同时向安装器提供其所需的小容量 GPU BAR 以保证安装界面正常显示。随后在软件更新中安装 macOS 26；更新后的首次开机会自动完成 Tahoe 版驱动的设置并自行重启一次。取消 Tahoe 准备则会恢复一切原状。


   



如果重启后出了问题


在 OpenCore 启动菜单选择 1401: Remove NVIDIA driver，再选你的 macOS 磁盘。1401 会移除驱动并重启，本机即恢复到安装前的状态（包括 OpenCore 配置）。屏幕可能保持黑屏直到第二次重启完成。









检查我的 EFI


将本机启动所用的 OpenCore 配置与同类机型验证可行的设置做对比，解释需要修改的地方并给出步骤。它只读取、不做任何更改。会要求输入一次密码。













工具


挂载 EFI


EFI 分区存放着你的引导设置。1401 会找到本机启动所用的那个分区，挂载并在访达中打开。会要求输入一次密码。


 


启动文字（啰嗦模式）


开机时显示 macOS 的启动过程，代替苹果标志。开机卡住时很有用。下次重启后生效。


 


内置屏幕亮度（笔记本）


适用于内置屏幕直连 NVIDIA GPU 的笔记本（MUX 已设为 Discrete 或 dGPU）。它让驱动从笔记本固件读取屏幕亮度控制。默认关闭，因为该调用曾导致部分电脑在 GPU 启动时卡住；如果你也卡在那里，请在启动菜单选择 1401: Start once without NVIDIA driver，然后在这里把它关掉。


 


HiDPI（Retina）分辨率


让 HiDPI 的"逻辑分辨率"生效，例如在 2560 x 1440 屏幕上使用 1920 x 1080，包括用 BetterDisplay 等工具添加的分辨率。没有它，这类分辨率会被拒绝并回退。驱动会以最高两倍于屏幕尺寸的分辨率绘制桌面，显存占用会更大。下次重启后生效。


 


AMD / Intel GPU 和 NPU 驱动（测试）


面向 macOS 没有驱动的 AMD 和 Intel GPU（Ryzen APU、Radeon RX 7000/9000、Intel Iris Xe 与 Arc 显卡），以及 Intel Core Ultra 和 AMD Ryzen AI 处理器中的 NPU。这是早期测试版：你"发送日志"上报的信息就是它被修好的途径。它只从 linux-firmware 下载你的 GPU 和 NPU 所需的固件（每个文件都校验），下次重启后生效。


如果这块 GPU 正在驱动你的屏幕，屏幕可能保持黑屏。那时请在启动菜单选择 1401: Start once without NVIDIA driver（它也会暂停该驱动），然后在这里关掉。


 


测试计划。 测试驱动开启期间，1401 会在每次重启后发送一份简短报告：驱动的内核消息、崩溃记录，以及你的 GPU 型号和构建版本（姓名和序列号已移除）。随时可以退出。


  


Intel Xe 显卡（WhateverXe，测试）


面向 macOS 15.8 / 26.7 及更高版本上的 Tiger Lake、Alder Lake 和 Raptor Lake Intel 显卡。它使用 b00t0x 的 WhateverXe：1401 先把它加入 OpenCore，你重启后再按一次开启来安装其显卡组件。这些组件直接来自作者的 GitHub，逐个校验。开启期间 WhateverGreen 会被关闭；关闭会恢复一切。


如果重启后屏幕黑屏，请在启动菜单选择 1401: Start once without NVIDIA driver：那次启动同样不会加载 WhateverXe。然后在这里关掉。


 


麦克风与摄像头


装上驱动后，macOS 在应用使用麦克风或摄像头前不再询问，导致 Discord 之类的应用只有静音，也永远不会出现在"隐私与安全性"里。在这里选择应用，授权其使用麦克风、摄像头和屏幕录制。


 


测绘我的 GPU（实验性）


对本机 GPU 做几分钟的测量：Metal 报告的内容、正确性检查、显存与算力速度，以及小型测试着色器。不做任何更改，也不动显示模式。结果保存在日志文件夹，"发送日志"会上传它，让下一版驱动能为你的显卡调优。


 


ARM 应用（自愿开启）




 暂不


专为 Apple 芯片构建的应用可以被转译到本机运行。小应用转译需几分钟，大应用可能要一小时以上。原应用不会被改动：转译副本存放在"应用程序 > NullMoth ARM"。关闭此功能会移除转译器和已转译的副本，你的 2.7 驱动不受影响。


    






 




Homebrew


与 Apple 芯片 Mac 一样并排使用两套 Homebrew：ARM 版在 /opt/homebrew，安装 Homebrew 的 Apple 芯片软件包并为本机转译；Intel 版在 /usr/local，原生运行但多数要从源码构建，因为 Homebrew 已停止发布 Intel 软件包。在终端里，abrew 始终是 ARM，ibrew 始终是 Intel，brew 则由你在下面选择。

还有问题？


发送日志


1401 会发送它的操作记录、驱动状态、崩溃报告、OpenCore 启动日志和数字化的设备映射，姓名、序列号和地址都会移除。你会得到一个报告 ID，可以贴在 NullMoth Discord 里求助。


 


录下闪烁画面：屏幕闪烁时按下它。1401 会录制 20 秒驱动向显示器输出画面的过程，随日志一起发送。




崩溃报告


如果驱动导致本机崩溃，1401 会在下次登录时询问是否生成报告。它是桌面上的一个文本文件，包含你的硬件信息和故障原因，姓名、Mac 名称、序列号、地址和文件路径都已移除。1401 绝不会自行发送它。




   


可选诊断


此版本不支持采集。发送日志仍会收集硬件、内核和崩溃证据。安全设置没有任何更改。


 


检查可用性不会留下任何痕迹。已保存的回执需要单独的会话上传权限和一次独立的"发送日志"确认。
